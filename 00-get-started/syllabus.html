Web Communication 2026-27

v. of Sep. 21th

This course introduces students to the principles and practice of web communication and web design, from basic HTML/CSS to JavaScript, responsive layout, and beyond. All lecture materials, exercises, and boilerplate codes are published in the course GitHub repository. Please register for a github.com/ account using your @studenti.unimi.it account and join github.com/education.

5 Software Tools

Installed these to follow the course and complete exercises:

  • Web browser Firefox will be used in class.

  • Package manager to quickly install/update apps. For Win: install chocolatey.org; For Mac: install brew.sh.

  • Code editor code.visualstudio.com/; also available online at vscode.dev/.

  • document converter from pandoc.org/; also available online at pandoc.org/try/.

  • Renderer quarto.org/ for authoring and rendering course materials (HTML slides or PDF)

  • Version control software git-scm.com/.

  • A modern Git manager, e.g., fork.dev.

6 Exams

Prepare a Web Communication project consisting of a pitch deck for a technical audience, a stub web page with styles, AV contents, links etc parked on your GitHub space and coordinated with email campaign plans and social media presence (IG, FB, X, WA etc.). The oral exam consists of presenting the technical side of your project and showing ownership of the code.

Exam dates December 18 and 19 in person at the Sala seminari on the second floor of the Passione building (i.e., right above the Laboratorio 2). Exam slots are bookable via Teams. Arrangements are available for Erasmus/exchange students who need to leave Milan earlier. For 2027, January 13 and 14 (TBC) and dates in March and July.
