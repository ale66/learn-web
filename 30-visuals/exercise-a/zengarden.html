One Page, Many Looks

The same HTML, dressed by different CSS

This page never changes. Only the stylesheet in the <head> does. Swap one line and layout, colour, type and imagery all follow.

The markup follows the structure of the CSS Zen Garden, so every design in its archive can be plugged in.

Structure First

Good visual communication starts from meaningful structure: headers, sections, asides, lists. Presentation is a separate layer that can be replaced without touching the content.

Compare two designs and notice what moved: the sidebar, the headings, the footer links. The words stayed exactly where they were in the source.

What Is Happening Here?

The browser downloads one stylesheet from the CDN and applies it to the elements below. Each design targets the same ids and classes: #zen-intro, .summary, .preamble, .explanation, .participation, .benefits, .requirements and the .sidebar.

Empty .extra1 to .extra6 elements at the end of the page exist only so designers can hang extra imagery on them.

Try It Yourself

Open this file in a text editor, find the active <link> line and replace the design number, for instance 001 with 221. Save, reload, compare.

Then change the same number in the file name too: the path has the form NNN/NNN.css.

Copy a few paragraphs, shorten them, make them longer: see how each design copes with more or less text.

Why It Matters

Separating content from presentation makes pages easier to maintain, to translate and to make accessible. It also lets the same message reach different readers in different forms.

Things To Watch

Some designs rely on images and web fonts that live next to the CSS; the CDN serves them too, so you need to be online.

Some designs break at narrow widths, others adapt gracefully: resize the window and observe.

Always check the effect on long headings and on the sidebar lists.

Design numbers run from 001 to 221; a few of the older ones use fixed widths.
